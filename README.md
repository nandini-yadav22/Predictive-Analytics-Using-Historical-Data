# Predictive Analytics Using Historical Data

##  Project Overview

This project focuses on predictive analytics using historical sales data. 
The main objective is to analyze past sales and revenue patterns and build 
machine learning models that can be used to predict future revenue trends.

The project includes data cleaning, exploratory data analysis, feature 
engineering, predictive modeling, model evaluation, visualization, and 
future revenue forecasting.

---

##  Objectives

- Analyze historical sales and revenue data
- Clean and preprocess the dataset
- Identify important trends and patterns
- Perform exploratory data analysis (EDA)
- Build predictive regression models
- Compare model performance using evaluation metrics
- Forecast future revenue
- Generate useful business insights from the analysis

##  Dataset

The project uses historical sales data containing the following features:

- Date
- Orders
- Customers
- Returns
- Marketing Spend
- Average Order Value
- Revenue

The dataset is used to analyze historical trends and build predictive
models for revenue forecasting.

## Machine Learning Models

### Linear Regression

Linear Regression is used as a baseline model to predict revenue using
historical sales-related features.

### Random Forest Regression

Random Forest Regression is used to capture more complex relationships
between the input features and revenue.
---

## Model Evaluation

The models are evaluated using:

- MAE (Mean Absolute Error)
- RMSE (Root Mean Squared Error)
- R² Score

These metrics are used to understand the prediction error and overall
model performance.
